Git is a version control system
This is my first git library

how to use git?
    step1: edit your file
    step2: use the command "git add test.txt"
    step3: use the command "git commit -m "your changed information""

you can use the command "git status" to check the state of the git library right now.
if you didn't refresh the changed version in git library, you can use the command "git diff" to check the changed part

"git log" is a command to check every version of the file and see what has been changed.

"git reset" is a command to souce the previous version or the specific version,
            " --hard" back to the version has been commit
            " --soft" back to the version has not been commit
            " --mixed" back to the version has been add but not commit
" git reflog" can be used to move to the version after any history command.你可以使用这个命令回到任何命令执行之后的版本    

"git checkout -- filename" is a command to restore the version from the work area. (But when you have other change has no been commit, the delete file cannot be restore.)

STEPS to connect the local git repo to the remote repo
    use command "git remote add origin git@github.com:brcheng44/git_test.git" to connect to the remote repo, change the name of the repo you are using.
    use command "git branch -M main" to create a new branch named main, "-M" means force rename.
    use command "git push -u origin main" to push your local repo to the remote repo. "-u" should be used if you push the repo first time.
    use command "git push origin main" to push your local repo to remote repo branch "main".

"git branch -m master main" change the name of the branch "master" to "main"

HOW to clone the remote repo:
    使用 "git remote -v" 查看远程库的信息
    最好的方式是每次从远程库克隆一个repo，然后在本地修改完该库之后再push到remote上
    可以使用" git clone git@github.com:brcheng44/git_test.git" 克隆一个远程库到本地
    默认情况下，git clone 复制出来的远程 repo 只有 main 一个分支，如果要在其他分支上开发，就需要创建远程origin的branch到本地
    需要在本地创建新的分支：git checkout -b branch1 origin/branch1
    然后在本地的 branch 上修改，随后 push 到 remote: git push origin branch1
    如果有人和你在向相同的分支上 push 并且发生了冲突，则可以重新 git pull 之后再在本地修改完 push
    如果pull失败，可能是本地分支 branch1和远程分支origin/branch1 之间没有建立链接（no tracking information），则使用该设置：
        git branch --set-upstream-to=origin/branch1 branch1
        例如：[brcheng@brchengdeMacBook-Air learngit % git branch --set-upstream-to=origin/new_branch new_branch
        分支 'new_branch' 设置为跟踪 'origin/new_branch'。]

Branch Management
    main就是一个分支，提交指向的不是git库，而是 main 这个分支，也可以创建并提交至别的分支
    合并分支就是将master的指针移动到某个branch上
    git checkout -b new_branch_name 等同于创建并且切换到新的分支，名字为 new_branch_name:{
        git branch new_branch_name 用于创建新的branch，命名为 new_branch_name
        git checkout new_branch_name 用于切换到 new_branch_name
    }
    git branch 查看当前分支
    切换分支之后添加（add）和提交（commit）都会发生在当前分支
    当分支完成后需要与main进行合并时，切换至 main分支

    git merge new_branch_name进行合并
    合并后原有分支仍然会保留

Fix Bug
    当bug出现在main上时，branch1上有未提交的工作，此时需要：
    step1: git stash [保存branch1当前的工作状态]
    step2: git switch main [转到main上]
    step3: git switch -c bug_fix [创建新的分支修复bug，并且提交]
    step4: git switch main
            git merge bug_fix [转回main，并且合并修复bug的分支]
    step5: git switch branch1
            git cherry-pick 290e645 [转到branch1，并且从main复制一份更改内容]
    step6: git stash pop [恢复之前保存的工作状态，但是此时会发生冲突，选择保留两者的内容，然后手动更改branch1上的内容]
    step7: 继续branch1 的工作内容
