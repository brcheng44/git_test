Git is a version control system
This is my first git library

how to use git?
step1: edit your file
step2: use the command "git add test.txt"
step3: use the command "git commit -m "your changed information""

you can use the command "git status" to check the state of the git library right now.
if you didn't refresh the changed version in git library, you can use the command "git diff" to check the changed part

"git log" is a command to check every version of the file and see what has been changed.

"git reset" is a command to souce the previous version or the specific version,
            " --hard" back to the version has been commit
            " --soft" back to the version has not been commit
            " --mixed" back to the version has been add but not commit
" git reflog" can be used to move to the version after any history command.你可以使用这个命令回到任何命令执行之后的版本    

"git checkout -- filename" is a command to restore the version from the work area. (But when you have other change has no been commit, the delete file cannot be restore.)

STEPS to connect the local git repo to the remote repo
use command "git remote add origin git@github.com:brcheng44/git_test.git" to connect to the remote repo, change the name of the repo you are using.
use command "git branch -M main" to create a new branch named main, "-M" means force rename.
use command "git push -u origin main" to push your local repo to the remote repo. "-u" should be used if you push the repo first time.
use command "git push origin main" to push your local repo to remote repo branch "main".
